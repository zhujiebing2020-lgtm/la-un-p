# la-un-p｜从人设到轨迹

**可审计的 AI 角色状态框架 · 朱洁冰**

研究如何把角色的经历、当前压力和身份承诺，转成可追踪的状态变化，并约束后续对白与行动。la-un-p是项目名称，不是已有的人格量表。

## 先看一个问题

同样面对“你先垫200元”，一个曾被对方放鸽子的人，会不会要求先核对清单？如果改变了选择，系统能否指出依据、保留条件，并确认钱到底有没有转出？我们希望这条过程可检查，而不是只得到一句好听的台词。

[五分钟看完整示例](EXAMPLE.md) → [论文 v0.3.2](la-un-p_theory_paper.md) → [方法附录](METHODS.md) → [测评计划](EVALUATION.md)。按需阅读，不需要先读完整知识库。

```text
经历与当前事件 → 带证据的解释 → 状态计算与合法转移
→ 约束候选表达/行动 → 记录实际后果 → 后续状态与事件记账
```

## 怎么检查

无需模型、API或第三方依赖，在Python 3中运行：

```sh
python3 examples/gate_example.py
```

这只验证同一当前输入下，历史量能否改变过阈资格。它不运行完整角色，不验证自然语言解释，更不证明优于记忆代理。完整研究harness尚未随本次文稿公开，不能把这个脚本当作全部系统复现。

## 研究位置

理论来源和组件可以来自已有研究；本项目检验它们组合后的执行约束、可追溯性与行为增量。对照必须保留强记忆与反思能力、匹配信息与预算，允许无收益或失败。理论来源与相关工作见论文§9和参考文献。
